# 英语句子随机抽签

这是一个纯静态网页，可以直接发布到 GitHub Pages。

## 使用方法

- 打开 `index.html`，进入“随机抽签”页面。
- 在“句子库”里添加英语句子和中文释义。
- 在“学生名单”里添加班级学生姓名。
- 回到“随机抽签”，选择抽取人数，然后点击“开始随机抽签”。
- 如果学生不在，可以点击对应卡片里的“换人”。

## 修改默认数据

发布到 GitHub 后，默认数据来自这两个文件：

- `data/sentences.json`
- `data/students.json`

网页中新增或删除的数据会保存在当前浏览器的本地存储里，不需要服务器。
